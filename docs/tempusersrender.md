## С чего начать показ (связки)

1. `demo-business` → вход на портал → каталог решений.
2. «Подбор решения» → описать задачу (например: «Мы горнодобывающая компания, хотим заранее узнать о поломках конвейеров») — ассистент уточнит и подберёт решение.
3. `demo-admin` → «Запросы бизнеса» → передать запрос вузу.
4. `demo-rep` → ответить компании; `demo-business` → увидеть статус и ответ в «Мои запросы».
